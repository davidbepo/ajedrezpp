# ajedrezpp
Port a C++ de mi [ajedrez en python](https://github.com/davidbepo/pyjedrez) usando SFML

Requisitos:
tener instalado SFML y un compilador C++
el comando que uso yo para compilar:
clang++ -s -O3 -mtune=native -Wall -pthread -o ajedrez ajedrez.c++ -lsfml-graphics -lsfml-window -lsfml-system -fuse-ld=mold
